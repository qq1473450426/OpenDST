# OpenDST 精简版

仅保留两个核心任务：**Math-Task（心算任务）** 与 **Speech-Task（自由演讲任务）**。已移除原研究流程中的问卷、VAS、PANAS、JATOS、参与者数据上传等功能。

## v0.3.0

本版本重点更新：

- 增加测试开始页：填写年龄和性别后进入 Math-Task。
- Math-Task 保留固定 75% 参考值，用于与参与者实时正确率进行比较。
- 隐藏整个 Math-Task 的“剩余测试总时长”，参与者只看到当前题目的倒计时。
- 电脑端改为使用物理键盘/数字小键盘输入，不再显示虚拟数字键盘。
- 支持数字键 `0-9`、`Backspace` 删除、`Esc` 清空。
- Math-Task 完成后增加独立的 Speech-Task 介绍页面。
- Speech-Task 继续执行 3 个场景，每个场景准备 10 秒、演讲 20 秒。
- 保留摄像头、麦克风、声音可视化以及约 1 秒无声音后的“请继续说话”提示。

## 重要说明：物理小键盘与随机键盘

电脑端现在直接监听物理键盘的 `0-9` 数字输入，因此不再需要虚拟数字键盘。

原实验中的“数字键随机调换”依赖**屏幕上的虚拟键盘按键位置随机化**。使用物理数字小键盘后，硬件按键位置无法由网页改变，因此该视觉键盘扰动不再适用于物理小键盘。项目保留了连续答对 3 题后进入 4 题干扰阶段的状态计数，但不会改变真实小键盘的数字映射。

## Math-Task

- 总任务时间：90 秒。
- 初始每题时间：3 秒。
- 题目：1～99 范围内的加、减、乘、除，结果为 1～99 的整数。
- 连续正确 3 题：当前单题时间缩短 10%。
- 连续错误/超时 3 题：当前单题时间延长 10%。
- 连续 5 次没有输入：显示参与提示，并让下一题使用加法。
- 当前正确率实时显示。
- 参考值固定为 75%。
- 参与者只看到当前题目的剩余时间，不显示整个 90 秒任务的剩余时间。

### 物理键盘

| 按键 | 功能 |
|---|---|
| `0`～`9` | 输入数字 |
| `Backspace` | 删除最后一位 |
| `Esc` | 清空当前答案 |

## Speech-Task

Math-Task 结束后不会直接进入 Speech-Task，而是先进入说明页。

说明页结束后进入三个演讲场景：

1. 准备 10 秒 → 演讲 20 秒
2. 准备 10 秒 → 演讲 20 秒
3. 准备 10 秒 → 演讲 20 秒

演讲阶段包括：

- 前置摄像头预览。
- 麦克风实时采集。
- 声音可视化。
- 低于声音阈值持续约 1 秒时显示“请继续说话”。
- 演讲阶段红色视觉闪烁刺激。

## 年龄/性别参考值

当前版本会让参与者填写年龄和性别，但**75% 仍然是固定参考值**，并不会从真实年龄/性别数据库动态查询。

年龄和性别目前用于建立实验界面中的参与者属性字段；如果以后需要接入真实的年龄/性别分组基准数据，可以在 `src/config.js` 或独立数据模块中替换参考值计算逻辑。

## 安装

需要 Node.js 环境。

```bash
npm install
npm start
```

如果项目使用 Vite，开发服务器通常为：

```text
http://localhost:5173
```

## 摄像头和麦克风权限

首次运行时浏览器会请求摄像头和麦克风权限。生产环境建议使用 HTTPS，因为现代浏览器通常只允许安全上下文访问 `getUserMedia()`。

## 参数修改

主要实验参数集中在 `src/config.js`：

```js
math: {
  totalSeconds: 90,
  initialQuestionMs: 3000,
  correctStreak: 3,
  correctTimeFactor: 0.9,
  wrongStreak: 3,
  wrongTimeFactor: 1.1,
  randomKeyboardTasks: 4,
  noInputStreak: 5,
  referenceScore: 75,
}
```

Speech-Task：

```js
speech: {
  preparationMs: 10000,
  speakingMs: 20000,
  questions: [...],
  silenceMs: 1000,
  silenceThreshold: 7,
}
```
