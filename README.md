# OpenDST 精简版

仅保留两个核心任务：**Math-Task（心算任务）** 与 **Speech-Task（自由演讲任务）**。

## v0.3.1

本版本完善了实验入口、Math → Speech 流程和计时逻辑：

- 测试开始前填写年龄和性别。
- 根据填写的信息显示“X岁 + 性别”的**模拟参考组**标签。
- 参与者正确率实时计算并与固定 **75%** 模拟参考值比较。
- 明确标注 75% 为模拟参考值，不代表真实人群统计数据。
- Math-Task → Speech-Task 之间增加独立的 Speech Task 介绍页。
- Math-Task 总时长固定为 90 秒；参与者界面不显示整个测试的剩余时间。
- 参与者仅看到当前题目的倒计时。
- 电脑端使用物理数字小键盘/数字键输入，不显示虚拟数字键盘。
- 修正全局 90 秒计时与单题计时相互重置的问题。

## 实验流程

```text
个人信息
  ↓
Math-Task（90 秒）
  ↓
Speech Task 介绍
  ↓
Speech-Task（3 个问题）
  ↓
测试结束
```

## 个人信息与模拟参考值

开始测试时需要填写：

- 年龄：1～120 岁整数。
- 性别：男 / 女 / 其他或不便说明。

当前版本不会查询真实数据库，也不会声称获得真实同龄人数据。界面会根据参与者填写的信息生成“X岁 + 性别模拟参考”标签，并始终使用固定 **75%** 作为参考线。

因此，实验界面的比较逻辑为：

```text
参与者实时正确率  ↔  75% 模拟参考值
```

如果后续拥有经伦理审批和授权的真实基准数据，可再替换为真实年龄/性别分组基准。

## Math-Task

- 总任务时间：90 秒。
- 初始每题时间：3 秒。
- 每题使用 1～99 范围内的整数。
- 加法结果限制在 1～99。
- 减法结果限制在 1～99。
- 乘法结果限制在 1～99。
- 除法为整除，商和被除数均在有效范围内。
- 连续正确 3 题：当前单题时间缩短 10%。
- 连续错误 3 题：当前单题时间延长 10%。
- 连续 5 次无输入/超时：显示参与提示，并强制下一题为加法。
- 实时显示参与者正确率。
- 同时显示固定 75% 模拟参考值。
- 不显示整个 90 秒测试的剩余时间。

### 物理数字小键盘

不再提供网页虚拟数字键盘，直接监听电脑物理键盘：

| 按键 | 功能 |
|---|---|
| `0`～`9` | 输入数字 |
| `Backspace` | 删除最后一位 |
| `Esc` | 清空当前答案 |

浏览器可以读取按键事件，但不能改变真实硬件数字小键盘的物理键位。因此原本依赖虚拟键盘位置变化的“随机键盘布局”无法在物理小键盘上实现。

## Speech Task 介绍页

Math-Task 完成后先进入独立介绍页，参与者确认后才进入 Speech-Task。

介绍内容包括：

- 共 3 个口头表达问题。
- 每个问题准备 10 秒。
- 每个问题回答 20 秒。
- 使用前置摄像头和麦克风。
- 显示声音可视化。
- 持续约 1 秒未检测到声音时提示“请继续说话”。
- 演讲阶段使用红色视觉刺激。

## Speech-Task

当前 3 个问题为：

1. 请描述一次你被他人批评的情形。
2. 请描述一次你在工作或学习中犯错的经历。
3. 请说明一个你认为自己需要改进的方面。

参数集中在 `src/config.js`，便于后续修改。

## 安装与运行

需要 Node.js。

```bash
npm install
npm start
```

Vite 开发服务器通常使用：

```text
http://localhost:5173
```

生产或实验部署时，摄像头/麦克风建议使用 HTTPS。浏览器首次运行会请求相应媒体权限。
