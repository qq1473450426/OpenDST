# OpenDST 精简版

仅保留两个核心任务：**Math-Task（心算任务）** 与 **Speech-Task（自由演讲任务）**。

## v0.3.2

本版本重点统一 Math-Task 与 Speech-Task 的实验界面布局：

- Speech-Task 改为与 Math-Task 一致的**左侧摄像头 + 右侧任务区**双栏结构。
- 桌面端采用约 **40% 摄像头 / 60% 任务区**。
- 左侧摄像头保持全高度显示，并固定实时采集画面。
- 右侧集中显示题目、准备/回答状态、倒计时、声音可视化、声音强度、进度条和提示信息。
- Speech-Task 的红色视觉刺激只作用于右侧任务区，不覆盖摄像头区域。
- 窄屏设备自动切换为上下布局，避免内容被裁切。
- 优化摄像头/麦克风不可用时的错误提示。

## 实验流程

```text
个人信息
  ↓
Math-Task（90 秒）
  ↓
Speech Task 介绍
  ↓
Speech-Task（3 个问题）
  ↓
测试结束
```

## 个人信息与模拟参考值

开始测试时需要填写：

- 年龄：1～120 岁整数。
- 性别：男 / 女 / 其他或不便说明。

当前版本不会查询真实数据库，也不会声称获得真实同龄人数据。界面会根据参与者填写的信息生成“X岁 + 性别模拟参考”标签，并始终使用固定 **75%** 作为参考线。

比较逻辑为：

```text
参与者实时正确率  ↔  75% 模拟参考值
```

## Math-Task

- 总任务时间：90 秒。
- 初始每题时间：3 秒。
- 每题使用 1～99 范围内的整数。
- 加法结果限制在 1～99。
- 减法结果限制在 1～99。
- 乘法结果限制在 1～99。
- 除法为整除，商和被除数均在有效范围内。
- 连续正确 3 题：当前单题时间缩短 10%。
- 连续错误 3 题：当前单题时间延长 10%。
- 连续 5 次无输入/超时：显示参与提示，并强制下一题为加法。
- 实时显示参与者正确率。
- 同时显示固定 75% 模拟参考值。
- 不显示整个 90 秒测试的剩余时间。

### 物理数字小键盘

不再提供网页虚拟数字键盘，直接监听电脑物理键盘：

| 按键 | 功能 |
|---|---|
| `0`～`9` | 输入数字 |
| `Backspace` | 删除最后一位 |
| `Esc` | 清空当前答案 |

浏览器可以读取按键事件，但不能改变真实硬件数字小键盘的物理键位。因此原本依赖虚拟键盘位置变化的“随机键盘布局”无法在物理小键盘上实现。

## Speech Task 介绍页

Math-Task 完成后先进入独立介绍页，参与者确认后才进入 Speech-Task。

介绍内容包括：

- 共 3 个口头表达问题。
- 每个问题准备 10 秒。
- 每个问题回答 20 秒。
- 使用前置摄像头和麦克风。
- 显示声音可视化。
- 持续约 1 秒未检测到声音时提示“请继续说话”。
- 演讲阶段使用红色视觉刺激。

## Speech-Task

当前 3 个问题为：

1. 请描述一次你被他人批评的情形。
2. 请描述一次你在工作或学习中犯错的经历。
3. 请说明一个你认为自己需要改进的方面。

### Speech-Task 布局

桌面端结构固定为：

```text
┌──────────────────────┬──────────────────────────────────────┐
│                      │                                      │
│   前置摄像头实时画面  │       Speech Task 任务区域            │
│                      │                                      │
│       40%            │              60%                     │
│                      │  题目 / 倒计时 / 声音可视化 / 提示     │
│                      │                                      │
└──────────────────────┴──────────────────────────────────────┘
```

演讲阶段的红色视觉刺激只改变右侧任务区背景，左侧摄像头保持可见。

## 安装与运行

需要 Node.js。

```bash
npm install
npm start
```

Vite 开发服务器通常使用：

```text
http://localhost:5173
```

生产或实验部署时，摄像头/麦克风建议使用 HTTPS。浏览器首次运行会请求相应媒体权限。
