# OpenDST 精简版

仅保留两个核心任务：**Math-Task（心算任务）** 与 **Speech-Task（自由演讲任务）**。

## v0.3.3

本版本重点修复 Speech-Task 的实际显示布局和麦克风声音检测：

- Speech-Task 桌面端严格采用与 Math-Task 相同的**左摄像头 + 右任务区**结构。
- 左侧占 **40%**，显示前置摄像头实时画面并保持全高度。
- 右侧占 **60%**，显示题目、倒计时、声音可视化、声音强度、进度和状态。
- 演讲阶段红色视觉刺激仅作用于右侧任务区。
- 声音检测改用麦克风时域 **RMS 振幅**，不再使用容易误判的 FFT 平均值。
- Web Audio 初始化后主动 `resume()`，降低 AudioContext 暂停造成的检测失败概率。
- 正常说话时声音强度应出现明显变化；持续约 1 秒低于阈值后才显示“请继续说话”。
- 增加摄像头/麦克风权限错误提示。

## 实验流程

```text
个人信息
  ↓
Math-Task（90 秒）
  ↓
Speech Task 介绍
  ↓
Speech-Task（3 个问题）
  ↓
测试结束
```

## Speech-Task 布局

桌面端固定为：

```text
┌──────────────────────┬──────────────────────────────────────┐
│                      │                                      │
│   前置摄像头实时画面  │          Speech Task 任务区           │
│                      │                                      │
│                      │       题目 / 倒计时 / 回答状态         │
│       40%            │       声音可视化 / 声音强度            │
│                      │                                      │
│                      │                 60%                  │
└──────────────────────┴──────────────────────────────────────┘
```

这与实验的 Math-Task 左摄像头/右任务区布局保持一致。演讲阶段的红色刺激只覆盖右侧任务区。

## 声音检测

Speech-Task 使用浏览器 `getUserMedia()` 获取麦克风，然后通过 Web Audio `AnalyserNode` 获取时域波形并计算 RMS：

```text
麦克风
  ↓
MediaStream
  ↓
AudioContext
  ↓
AnalyserNode
  ↓
时域 RMS
  ↓
声音强度 / 静音判断
```

当前静音判断规则：

- RMS 低于 `0.018`：进入静音计时。
- 连续低于阈值约 `1000ms`：显示“请继续说话”。
- 检测到超过阈值的声音：立即恢复为正常状态。

如果电脑系统把麦克风静音、浏览器没有麦克风权限，页面会显示相应错误提示。

## 个人信息与模拟参考值

开始测试时需要填写：

- 年龄：1～120 岁整数。
- 性别：男 / 女 / 其他或不便说明。

当前版本不会查询真实数据库。界面根据参与者填写的信息显示“X岁 + 性别模拟参考组”标签，并使用固定 **75%** 作为模拟参考线。

因此比较逻辑为：

```text
参与者实时正确率  ↔  75% 模拟参考值
```

75% 不代表真实人群统计数据。

## Math-Task

- 总任务时间：90 秒。
- 初始每题时间：3 秒。
- 每题使用 1～99 范围内的整数。
- 加法、减法、乘法、除法均限制有效结果范围。
- 连续正确 3 题：当前单题时间缩短 10%。
- 连续错误 3 题：当前单题时间延长 10%。
- 连续 5 次无输入/超时：显示参与提示，并强制下一题为加法。
- 实时显示参与者正确率和固定 75% 模拟参考值。
- 不显示整个 90 秒测试的剩余时间，仅显示当前题剩余时间。

### 物理数字小键盘

不提供网页虚拟数字键盘，直接监听电脑物理键盘：

| 按键 | 功能 |
|---|---|
| `0`～`9` | 输入数字 |
| `Backspace` | 删除最后一位 |
| `Esc` | 清空当前答案 |

浏览器不能改变真实物理数字小键盘的按键位置，因此原虚拟键盘的位置随机化无法在物理小键盘上复现。

## Speech Task 介绍页

Math-Task 完成后先进入独立介绍页，参与者确认后才进入 Speech-Task。

- 共 3 个口头表达问题。
- 每题准备 10 秒。
- 每题回答 20 秒。
- 使用前置摄像头和麦克风。
- 显示声音可视化。
- 持续约 1 秒未检测到声音时提示“请继续说话”。
- 演讲阶段使用红色视觉刺激。

## Speech-Task 问题

1. 请描述一次你被他人批评的情形。
2. 请描述一次你在工作或学习中犯错的经历。
3. 请说明一个你认为自己需要改进的方面。

参数集中在 `src/config.js`。

## 安装与运行

需要 Node.js：

```bash
npm install
npm start
```

Vite 开发服务器通常使用：

```text
http://localhost:5173
```

生产或实验部署时，摄像头/麦克风建议使用 HTTPS。浏览器首次运行会请求相应媒体权限。
