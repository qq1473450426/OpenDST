# OpenDST 精简版

仅保留两个核心任务：**Math-Task（心算任务）** 与 **Speech-Task（自由演讲任务）**。

- 实时显示麦克风权限、麦克风音轨状态、enabled/muted。
- 显示 AudioContext 状态。
- 显示实际输入设备名称、采样率、声道数。
- 实时显示 RMS、环境噪声底、当前检测阈值。

- 增加“重新检测麦克风”按钮。

## 麦克风实时诊断

进入 Speech-Task 后，展开页面底部的 **“麦克风实时诊断”**。

面板包含：

| 项目 | 作用 |
|---|---|
| 权限 | 显示浏览器麦克风权限状态 |
| 麦克风状态 | 判断是否获得音频设备 |
| 音轨 | 显示 `live/ended`、`enabled/disabled`、`muted` |
| AudioContext | 显示 `running/suspended/closed` |
| 输入设备 | 显示当前实际麦克风名称 |
| 采样率 | 显示浏览器获得的采样率 |
| 声道 | 显示输入声道数量 |
| RMS | 当前麦克风时域振幅 |
| 噪声底 | 当前环境背景噪声估计 |
| 检测阈值 | 实际用于“是否在说话”的阈值 |
| 当前输入电平 | 图形化显示麦克风输入 |

### 如何判断问题

正常情况下：

```text
权限：已允许
麦克风状态：正常
音轨：live / enabled
AudioContext：running
RMS：说话时明显上升
当前输入电平：随说话变化
```

如果：

```text
RMS ≈ 0
输入电平 ≈ 0
```

即使摄像头正常，也说明浏览器没有收到有效麦克风音频数据。此时重点检查 Windows 的输入设备、系统麦克风权限、浏览器麦克风权限以及是否选择了正确的麦克风。

修改系统或浏览器权限后，可以直接点击 **“重新检测麦克风”**，无需刷新整个实验页面。

## 声音检测

Speech-Task 使用 `getUserMedia()` 获取摄像头和麦克风，并通过 Web Audio 的 `AnalyserNode` 计算时域 RMS。

声音判断使用：

1. 麦克风 RMS 振幅。
2. 环境噪声底动态估计。
3. 动态阈值与最低 RMS 阈值共同判断。
4. 连续约 1 秒低于阈值才显示“请继续说话”。

## Math-Task 键盘输入

Math-Task 不使用网页虚拟键盘。

进入题目后，答案输入框会自动获得焦点，并在切换题目后重新获得焦点。物理数字小键盘和数字行均可输入；Backspace 删除，Esc 清空。

浏览器不能改变真实物理数字小键盘的物理位置，因此原虚拟键盘的位置随机化无法在硬件键盘上复现。

## Math-Task

- 总任务时间：90 秒。
- 初始每题时间：3 秒。
- 每题使用 1～99 范围内的整数。
- 连续正确 3 题：当前单题时间缩短 10%。
- 连续错误 3 题：当前单题时间延长 10%。
- 连续 5 次无输入/超时：显示参与提示，并强制下一题为加法。
- 实时显示参与者正确率。
- 与固定 75% 模拟参考值比较。
- 不显示整个 90 秒测试的剩余时间，仅显示当前题剩余时间。

## 个人信息与模拟参考值

开始测试时填写年龄和性别。当前不会查询真实数据库；界面根据填写的信息显示“X岁 + 性别模拟参考组”标签，并使用固定 **75%** 作为模拟参考线。

75% 不代表真实人群统计数据。

## Speech Task 介绍页

Math-Task 完成后先进入独立 Speech Task 介绍页，确认后才进入 Speech-Task。

- 共 3 个问题。
- 每题准备 10 秒。
- 每题回答 20 秒。
- 使用前置摄像头和麦克风。
- 显示声音可视化。
- 演讲阶段右侧任务区进行红色视觉刺激。

## Speech-Task 问题

1. 请描述一次你被他人批评的情形。
2. 请描述一次你在工作或学习中犯错的经历。
3. 请说明一个你认为自己需要改进的方面。
