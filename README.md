# OpenDST 精简版

仅保留两个核心任务：**Math-Task（心算任务）** 与 **Speech-Task（自由演讲任务）**。

## v0.3.4

本版本统一实验主题，并重点修复电脑物理键盘焦点与麦克风检测：

- Math-Task 与 Speech-Task 使用统一的左摄像头 / 右任务区主题。
- 桌面端约 40% 摄像头 + 60% 任务区。
- Math-Task 答案框为真实 HTML input，进入任务后自动聚焦，切题后自动重新聚焦。
- 电脑数字小键盘和数字行均可输入；Backspace 删除、Esc 清空。
- Speech-Task 使用时域 RMS + 自适应环境噪声底检测声音。
- 麦克风音轨正常连接后显示“麦克风正常”。
- 静音约 1 秒后才提示“请继续说话”。

## 实验流程

```text
个人信息
  ↓
Math-Task（90 秒）
  ↓
Speech Task 介绍
  ↓
Speech-Task（3 个问题）
  ↓
测试结束
```

## 统一实验主题

桌面端固定：

```text
┌──────────────────────┬──────────────────────────────────────┐
│                      │                                      │
│   前置摄像头实时画面  │        任务 / 正确率 / 题目区域        │
│                      │                                      │
│        40%           │                  60%                 │
│                      │                                      │
└──────────────────────┴──────────────────────────────────────┘
```

Math-Task 右侧顶部显示参与者实时正确率和固定 75% 模拟参考值；Speech-Task 使用相同的双栏主题。

## 声音检测

Speech-Task 使用 `getUserMedia()` 获取摄像头和麦克风，并通过 Web Audio 的 `AnalyserNode` 计算时域 RMS。

声音判断使用：

1. 麦克风 RMS 振幅。
2. 环境噪声底动态估计。
3. 动态阈值与最低 RMS 阈值共同判断。
4. 连续约 1 秒低于阈值才显示“请继续说话”。

如果“声音强度”仍然长期为 0，应检查：

- 浏览器地址栏的麦克风权限是否为允许。
- Windows/macOS 系统输入设备是否选择了正确麦克风。
- 麦克风是否被系统静音。
- Chrome/Edge 的麦克风输入设备是否正确。

## Math-Task 键盘输入

Math-Task 不使用网页虚拟键盘。

进入题目后，答案输入框会自动获得焦点，并在切换题目后重新获得焦点。物理键盘输入直接写入该输入框：

| 按键 | 功能 |
|---|---|
| `0`～`9` | 输入数字 |
| 数字小键盘 `0`～`9` | 输入数字 |
| `Backspace` | 删除最后一位 |
| `Esc` | 清空当前答案 |

浏览器不能改变真实物理数字小键盘的物理位置，因此原虚拟键盘的位置随机化无法在硬件键盘上复现。

## Math-Task

- 总任务时间：90 秒。
- 初始每题时间：3 秒。
- 每题使用 1～99 范围内的整数。
- 连续正确 3 题：当前单题时间缩短 10%。
- 连续错误 3 题：当前单题时间延长 10%。
- 连续 5 次无输入/超时：显示参与提示，并强制下一题为加法。
- 实时显示参与者正确率。
- 与固定 75% 模拟参考值比较。
- 不显示整个 90 秒测试的剩余时间，仅显示当前题剩余时间。

## 个人信息与模拟参考值

开始测试时填写年龄和性别。当前不会查询真实数据库；界面根据填写的信息显示“X岁 + 性别模拟参考组”标签，并使用固定 **75%** 作为模拟参考线。

75% 不代表真实人群统计数据。

## Speech Task 介绍页

Math-Task 完成后先进入独立 Speech Task 介绍页，确认后才进入 Speech-Task。

- 共 3 个问题。
- 每题准备 10 秒。
- 每题回答 20 秒。
- 使用前置摄像头和麦克风。
- 显示声音可视化。
- 演讲阶段右侧任务区进行红色视觉刺激。

## Speech-Task 问题

1. 请描述一次你被他人批评的情形。
2. 请描述一次你在工作或学习中犯错的经历。
3. 请说明一个你认为自己需要改进的方面。

## 安装与运行

```bash
npm install
npm start
```

Vite 开发服务器通常使用 `http://localhost:5173`。生产或实验部署时，摄像头/麦克风建议使用 HTTPS。
